# Privacy and demonstration media

The beta does not request camera, microphone, storage, location or Internet permission. It opens the phone’s Camera application; photos/videos belong to that application. The accessibility service has broad capabilities for observing windows, filtering keys, showing its transition overlay and performing gestures/lock actions. Enable it only if you trust the code.

Diagnostic information stays in app-private preferences unless the user explicitly uses Android’s Share action. It can include remote device descriptors, key codes, timing, phone model/OS and service activity. Review diagnostics before sharing; do not upload full logs, Bluetooth dumps or screenshots without checking them. No automatic upload is implemented.

The repository demo is generated artwork and text. It contains no phone recording, screenshots, camera/gallery imagery, account details, Bluetooth addresses, notifications, device serials, raw logs or audio. It is labelled as an illustration rather than a recorded test. Its reproducible generator is included.

No ReefColor APK, remote firmware image, private app preferences, debug keystore or original phone recordings are distributed in this release.
